# 🎮 BxP-PROJECT

### Building multiplayer games from the ground up.

A **BxP-PROJECT** é uma organização independente focada no desenvolvimento de jogos multiplayer, combinando programação, arte, infraestrutura e tecnologia para criar experiências próprias.

Atualmente, nosso principal projeto é o **BxP — Comunidade**, um FPS multiplayer desenvolvido para dispositivos móveis.

---

## 🚀 Current Project

### BxP — Comunidade

Um **Mobile Multiplayer FPS** ambientado em uma comunidade urbana brasileira fictícia.

O projeto está sendo desenvolvido com foco em:

* 🎯 Combate multiplayer
* 📱 Experiência mobile
* 🌐 Arquitetura multiplayer
* 🖥️ Autoridade de servidor
* ⚡ Performance
* 🗺️ Mapas verticais e dinâmicos
* 🔫 Sistema de armas
* 🚗 Veículos
* 👥 Partidas competitivas

### MVP

O primeiro objetivo do projeto é construir uma experiência **Team Deathmatch** funcional, com suporte progressivo para partidas de até **10v10**.


## 🤝 Development Philosophy

O projeto busca manter um processo de desenvolvimento organizado e incremental.

### Principais princípios

* **Gameplay first**
* **Small iterations**
* **Test before scale**
* **Server authority**
* **Mobile performance**
* **Controlled scope**
* **Documented decisions**

Mudanças relevantes de arquitetura, escopo ou direção devem ser registradas e avaliadas antes de serem incorporadas ao projeto.
