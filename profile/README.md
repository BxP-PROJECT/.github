# 🎮 MEGA OPERAÇÃO

### Building multiplayer games from the ground up.

A **Mega Operação** é uma organização independente focada no desenvolvimento de jogos multiplayer, combinando programação, arte, infraestrutura e tecnologia para criar experiências próprias.

Atualmente, nosso principal projeto é o **Mega Operação**, um FPS multiplayer desenvolvido para dispositivos móveis.

---

## 🚀 Current Project

### Mega Operação

Um **Mobile Multiplayer FPS** ambientado em uma comunidade urbana brasileira fictícia.

O projeto está sendo desenvolvido com foco em:

* 🎯 Combate multiplayer
* 📱 Experiência mobile
* 🌐 Arquitetura multiplayer
* 🖥️ Autoridade de servidor
* ⚡ Performance
* 🗺️ Mapas verticais e dinâmicos
* 🔫 Sistema de armas
* 🚗 Veículos
* 👥 Partidas competitivas

### MVP

O primeiro objetivo do projeto é construir uma experiência **Team Deathmatch** funcional, com suporte progressivo para partidas de até **10v10**.
